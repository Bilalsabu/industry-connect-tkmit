# Industry Connect TKMIT

Official portal for **Industry Connect TKMIT** – Bridging Students & Industry through opportunities, collaboration, events, workshops, and career growth.

## 🚀 Features
- **Modern Glassmorphism Design**: High-performance, edge-to-edge full-screen portal with dynamic frosted-glass auto-hiding navbar.
- **Interactive Event Registration & Proposals**: Features workshops (e.g. LinkedIn Creation & Optimisation), Orientation, and Hackathons.
- **Headless Google Form Submissions**:
  - *Join the Team Application* directly synced to Google Forms / Google Sheets.
  - *Suggest an Idea Proposal* directly synced to Google Forms / Google Sheets.
- **Interactive About Us Page**: Executive committee showcase with dynamic network canvas and themed layout.

## 🛠️ Built With
- HTML5 & CSS3 (Custom Design System & Glassmorphism)
- JavaScript (Vanilla ES6+)
- Lucide Icons & Canvas Animations
- Node.js (Static Server)
